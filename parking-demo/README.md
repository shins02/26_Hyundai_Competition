# S J Story · 주차 메모
이 Mac에서 `주차메모.app`을 열거나 `주차메모_실행.command`를 더블클릭합니다. S J Story 차량 앱 옆에서 독립적으로 실행하는 시연입니다.

1. 샘플 메뉴에서 **지상 주차타워**를 선택하고 **주차 완료 · P단 모의 입력**을 누릅니다. 사진에 표시된 3F와 A-08을 읽어 ‘지상 3층 / A-08 표지 옆’이 뜹니다.
2. **야외 주차장**에서는 OUTDOOR, ZONE D, D-12를 읽어 ‘야외 · D구역 / D-12 표지 옆’으로 표시합니다. 층이 적혀 있지 않으면 층 번호를 추정하지 않습니다. 야외와 구역이 명시된 경우 기둥 번호 없이도 구역을 기록할 수 있습니다.
3. **지하 2층**에서는 B2와 C-17을 읽습니다. **기둥 미표시**에서 지하 층만 읽히면 새 알림을 만들지 않습니다. 내용을 직접 확인한 뒤 **확인·저장**으로 수정할 수 있습니다.
4. **사진 열기…**로 JPG·PNG·HEIC 사진도 시험할 수 있습니다. 층이나 구역이 둘 이상이거나 방향 안내가 섞여 있으면 수동 확인을 요청합니다.

실행 파일은 Apple Silicon Mac용입니다. 소스에서 다시 빌드하려면 Xcode가 있는 Mac에서 `./build.command`를 실행합니다. 사진은 Mac에서 처리하고 최근 층·기둥·시각 한 건만 로컬에 저장합니다. 이 버전은 실차 카메라 스트림이나 마이현대 푸시에 연결하지 않습니다. 합성 샘플의 판독 결과는 실제 주차장 정확도 측정값이 아닙니다.

# S J Story (Gilstory) — 졸음 경고를 휴식으로 이어 주는 차량용 이야기 앱

현대자동차그룹 차량용 앱 개발 공모전 출품용 프로젝트입니다. Pleos Connect(Android Automotive OS) 앱과, 시연 영상을 찍기 위한 **차량 화면 모의 테스터**로 이루어져 있습니다.

## 공모전 제출 정보

### 1. 앱 이름 및 한 줄 소개

- **앱 이름:** S J Story
- **한 줄 소개:** 장거리 운전 중 지나가는 지역의 이야기를 들려주고, 차량 졸음 경고가 오면 쉼터를 안내하며, 주차 후에는 주차 위치까지 알려 주는 차량용 음성 이야기 앱입니다.

### 2. 실행 방법

**A. Pleos Connect 에뮬레이터에서 APK 실행 (심사용)**

1. Android Studio → Tools → SDK Manager → SDK Update Sites → `+`
   - Name: `Pleos Connect System Image`
   - URL(Mac, Apple Silicon): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
2. SDK Platforms에서 **Pleos Connect v2.1.0 APIs arm64 System Image**(API 34)를 설치하고 Android Studio를 다시 시작합니다.
3. Device Manager → Automotive → **Pleos Connect v2.1.0**으로 AVD를 만들고 Cold Boot로 켭니다.
4. 부팅이 끝나면 APK를 설치합니다. 에뮬레이터 창에 APK 파일을 끌어다 놓아도 됩니다.
   ```bash
   adb install -r apk/신동주_SJStory_release.apk
   ```
5. 앱 목록에서 **S J Story**를 누르거나 아래 명령으로 실행합니다.
   ```bash
   adb shell am start -n com.gilstory.app/.ui.MainActivity
   ```
6. Pleos Connect Virtual Console로 기어(P/R/D), 경고등, 주행 시간을 바꾸면 앱이 반응합니다. 화면 오른쪽 **시연 패널**의 버튼(데모 주행, 운전 시간 +30분, 차량 졸음 경고, 쉼터 도착, 후진 주차 시연)으로도 같은 상황을 만들 수 있습니다.

**B. 소스에서 직접 빌드**

```bash
./gradlew :app:assembleDebug     # 테스트용 (휴대폰 에뮬레이터에도 설치 가능)
./gradlew :app:assembleRelease   # 제출용 release (서명 정보 keystore.properties 필요)
```

release 서명 키와 비밀번호(`keystore.properties`, `*.jks`)는 저장소에 올리지 않았습니다. 서명 정보 없이 `assembleRelease`를 실행하면 서명되지 않은 APK가 만들어집니다.

**C. 차량 화면 모의 테스터 (시연 영상용, PC Chrome)**

`simulator/start.command`를 더블클릭하면 Chrome에서 `http://localhost:8791`로 열립니다. 자세한 사용법은 아래 [모의 테스터로 시연 영상 찍기](#모의-테스터로-시연-영상-찍기)에 있습니다. 모의 테스터의 마이크 대답은 PC 시연용으로 Chrome 음성 인식을 쓰고, 차량 앱은 Pleos SpeechToText SDK만 씁니다.

## 모의 테스터로 시연 영상 찍기

1. `simulator/start.command`를 **더블클릭**합니다. Chrome에서 `http://localhost:8791`로 열립니다.
   - 마이크 음성 대답과 녹음 파일 재생은 이렇게 localhost로 열어야 안정적으로 동작합니다. HTML 파일을 직접 열면 마이크가 막힐 수 있습니다.
   - 처음에 Chrome이 마이크 사용을 물으면 **허용**을 누르세요.
2. 첫 화면에서 **영동고속도로 출발** 또는 **국도 · 영월 방향**을 고릅니다. `F` 전체 화면, `Z` 중앙 화면 확대.
3. 질문이 나오면 **말로 대답합니다.** "1번", "2번", "네", "아니요", "그만", "다른 거", "무서운 거"
   - **주행 중에는 화면 버튼이 눌리지 않습니다.** 선택지는 "이렇게 말하세요" 안내로만 보입니다. 정차(쉼터 도착) 중에만 터치할 수 있습니다.
   - 시연자는 키보드 `1` `2` `Y`로 "운전자가 그렇게 말한 것"을 대신 넣을 수 있습니다. 화면에는 보이지 않습니다.
4. 오른쪽 위 **⚙ 시연 패널**(`P`)에서 상황을 만듭니다: 🌙 밤, 👥 뒷좌석 탑승, ☕ 차량 졸음 경고, ⏱ +30분, 🅿 쉼터 도착, 🚗 다시 출발.
5. 앞유리 너머 도로는 경로에 맞춰 바뀝니다. 고속도로에서는 중앙분리대, 가드레일, 방음벽, 산이 나오고, 국도에서는 인도, 가로수, 가로등, 걷는 사람, 상가 건물이 나옵니다. 시연 패널의 **도로 풍경**에서 직접 고를 수도 있습니다. 사진이나 지도 이미지는 쓰지 않고 직접 그린 그림입니다.
6. 왼쪽 지도는 우리나라 지도(시·도 경계) 위에 경로를 층으로 쌓아 그립니다. 출발 전에는 전국이 보이고, 출발하면 경로로 확대됩니다. 경로선 속 흰 화살표가 가는 방향을 가리킵니다. 회색은 지나온 길, 파랑은 남은 길, P는 쉼터입니다.
   - 쉼터를 경유지로 넣으면 초록 핀이 떨어지고 "경유지 추가" 말풍선이 뜹니다. 내 차에서 쉼터까지 길이 초록으로 칠해지고, 지도가 그 구간으로 확대됩니다. 도착하면 "도착" 표시, 다시 출발하면 다녀간 쉼터는 회색 ✓로 남습니다.
   - 지도 데이터: Natural Earth(퍼블릭 도메인). `simulator/korea_map.json`에 줄여 넣어 인터넷 없이 동작합니다. 휴게소 위치는 대략 위치입니다.
   - 시뮬레이터 창을 **하나만** 열어 두세요. 같은 주소로 연 창이 둘이면, 한 창이 말하기 시작할 때 다른 창은 저절로 멈춥니다.

추천 시연 순서 (약 3분)
1. 낮, 영동고속도로 → 용인 처인성 이야기 → "1번"
2. ☕ 차량 졸음 경고 → 계기판에 경고등 → "덕평자연휴게소까지 5킬로미터 남았어요. 잠깐 쉬었다 갈까요?" → "네"
3. 🅿 쉼터 도착(P단) → "주차했어요. 듣던 이야기의 결말을 들을까요?" → "네" → 경고 때 멈춘 이야기의 결말 → 🚗 다시 출발
4. 🌙 밤 → "오싹한 이야기로 바꿀까요?" → "네" → 장화홍련전 → "1번"
5. (이어 듣기) 시연 패널 설정에서 **휴식 안내 중에도 이야기 이어 듣기**를 체크 → ⏱ +30분으로 누적 120분 → 쉼터 권유에 "아니요"(시연자 키보드 `2`) → "결말은 ○○킬로미터쯤 더 달린 뒤에 들려드릴게요" → 다른 이야기 → 거리가 차면 "기다리셨죠. 아까 그 이야기 결말 들려드릴게요."
6. (주차) 마지막 지역이 끝나면 저절로, 또는 키보드 `G`나 시연 패널의 **⏪ 목적지 도착 · 후진 주차**로 시작 → 지하주차장 통로(D단, 글자 인식 꺼짐) → R단에서 기둥 글자 인식(C-16, C-17, C-17) → P단 → 휴대폰 화면에 "지하 2층 · C-17 기둥 옆" 알림 → 알림을 누르면 위치와 사진

주차 장면의 기어와 카메라 영상은 모의 입력이고, 글자는 그려진 장면에서 Tesseract.js로 실제로 인식합니다. 인식 엔진을 인터넷에서 받으므로, 인터넷이 없으면 기록에 "인식 없이 시연값"이라고 표시하고 정해진 값으로 진행합니다. 휴대폰은 마이현대 앱 연동을 가정한 화면이며 실제 전송은 없습니다.

### 소개 영상 다시 만들기

시뮬레이터(`http://localhost:8791`)를 켠 뒤 `gilstory` 폴더에서 아래를 실행합니다. 자막과 장면 순서는 `tools/video/director.js`에 있고, 작업 폴더에는 약 1.5GB가 필요합니다.

1. `node tools/video/record.mjs <작업 폴더>`
2. `tools/voice/.venv/bin/python tools/video/mix.py <작업 폴더>`
3. `swiftc -swift-version 5 -O tools/video/compose.swift -o <작업 폴더>/compose`
4. `<작업 폴더>/compose <작업 폴더> <결과.mp4>`

### 휴식 안내 중 이야기: 두 가지 방식

| | ⏸ 쉬어 가기 (기본) | 🎧 이어 듣기 |
|---|---|---|
| 경고가 뜨면 | 듣던 이야기를 멈추고 쉼터를 권함 | 듣던 이야기를 멈추고 쉼터를 권함 |
| 장시간 운전만으로 휴식을 권한 뒤 | 이야기를 틀지 않음 | 이야기를 이어 감 |
| 장시간 운전 안내 때 미뤄 둔 결말 | 쉼터에 P단으로 정차하면 | 10~15km 더 달린 뒤 (그 전에 쉼터에 정차하면 쉼터에서) |
| 고르는 곳 | 앱: 정차 중 설정의 "휴식 안내 중에도 이야기 이어 듣기" 스위치 / 시뮬레이터: 시연 패널 설정 체크 | 〃 |

- 차량 주의 경고가 들어오면 두 모드 모두 재생을 중단합니다. 이어 듣기와 거리 기반 결말은 장시간 운전에 따른 휴식 안내에서만 적용합니다.
- 앱은 차량 누적 주행 거리(`Odometer.getCurrentDistanceDriven`, km로 가정)로 재고, 거리를 받을 수 없으면 평균 90km/h로 바꾼 시간으로 잽니다. 시뮬레이터는 지도에서 차가 달린 거리로 잽니다. 시연 주행은 빠르게 줄여 놓아서, 결말은 거리가 찬 뒤 듣던 이야기가 끝나면 나옵니다.
- 새로 추가한 안내 문장(결말 예고 등)은 아직 녹음 파일이 없어 컴퓨터 음성으로 읽습니다.

## 여는 방법에 따라 달라지는 점

| 여는 방법 | 녹음 목소리 | 마이크 대답 |
|---|---|---|
| **`simulator/start.command` 더블클릭 (권장)** | 모든 문장, 모든 목소리 | ✅ |
| HTML 파일을 직접 열기 (Safari, 앱 미리보기 등) | 기본 목소리의 시연용 문장 + 목소리 미리 듣기만. 나머지는 컴퓨터 음성으로 대신 읽고 화면에 안내 표시 | 막힐 수 있음 |

HTML을 직접 열면 브라우저가 옆 폴더(`audio/`)의 녹음 파일을 막는 경우가 있어서, 시연에 쓰는 문장과 미리 듣기 문장은 HTML 안에 직접 넣어 두었습니다.

## 목소리 바꾸기

### 기본 목소리: 무료 공개 음성 모델 (Supertone Supertonic 2)

시뮬레이터에는 **무료 공개 음성 모델 Supertonic 2**(Supertone, OpenRAIL-M 라이선스)로 미리 녹음한 목소리 4종이 들어 있습니다. 상업적으로도 쓸 수 있고, 금지되는 건 사칭(딥페이크) 같은 용도뿐입니다.

| 목소리 | 특징 |
|---|---|
| 밝은 여성 목소리 (F2) | 생기 있고 억양이 풍부함 (기본) |
| 차분한 여성 목소리 (F3) | 또박또박, 편안함 |
| 부드러운 남성 목소리 (M1) | 다정하고 가벼운 톤 |
| 중후한 남성 목소리 (M2) | 낮고 깊음, 오싹한 이야기에 잘 어울림 |

- **고르는 방법**: 차량 화면 아래 **🗣 목소리** 버튼, 또는 첫 화면의 **목소리 먼저 고르기**. ▶ 듣기로 미리 들어 보고 **고르기**를 누릅니다. 고른 목소리는 다음에 열 때도 기억합니다.
- **주행 중에도 바꿀 수 있습니다.** 🗣 목소리에서 "이 목소리로"를 한 번 누르거나, 질문을 듣는 중에 "남자 목소리", "차분한 목소리", "목소리 바꿔"라고 말하세요(시연자 키보드 `V`). 이야기를 끊지 않고 읽던 문장부터 새 목소리로 이어 읽습니다. 미리 듣기는 정차 중(이야기가 없을 때)에만 나옵니다.
- 다른 목소리(F1, F4, F5, M3, M4, M5)를 더 넣으려면 아래 명령을 실행한 뒤 `python3 simulator/build_simulator.py`를 실행하세요. 목소리마다 약 25MB입니다.

```bash
tools/voice/.venv/bin/python tools/voice/make_voice.py --voice F1 M3 --all
```

- 목소리 10종 비교 샘플: `tools/voice/samples/` (F1~F5 여성, M1~M5 남성)
- 이야기를 고치거나 추가하면 `python3 simulator/make_script.py`로 대본을 다시 뽑고, 위 명령으로 새 문장만 녹음합니다. 이미 있는 파일은 건너뜁니다.

### 직접 녹음한 목소리 넣기

`python3 simulator/make_script.py`가 만드는 대본(문장별 파일 이름 포함)에 맞춰 녹음 파일을 `simulator/audio/` 폴더에 바로 넣으면, 목소리 목록에 "직접 녹음한 목소리"로 나옵니다.

- `simulator/대본_시연용.csv`: 추천 시연에 나오는 문장
- `simulator/대본_전체.csv`: 시뮬레이터가 말할 수 있는 모든 문장

### 상용 AI 음성 자동 생성 (네이버 클라우드 CLOVA Voice API, 선택)

사람에 가까운 CLOVA Premium 화자(기본: 유나 `vyuna`)로 대본 전체를 한 번에 만들 수 있습니다. 장르별로 감정(기쁨)과 말 빠르기도 다르게 넣습니다. 상업적 사용이 가능한 유료 서비스입니다. 연예인(셀럽) 목소리는 별도 계약 없이 쓰지 않습니다.

```bash
export NCP_CLIENT_ID=발급받은_ID
export NCP_CLIENT_SECRET=발급받은_Secret
python3 simulator/clova_voice_tts.py
python3 simulator/build_simulator.py
```

### 컴퓨터 음성 (녹음 파일이 없을 때)

- 문장 단위로 나눠 읽고, 문장 사이에 사람처럼 쉽니다. 장르마다 말 빠르기와 높낮이가 다릅니다.
- macOS 기본 '유나'보다 **'유나(프리미엄)'**이 훨씬 자연스럽습니다. 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성에서 내려받으세요.

시연용 자막은 영상 설명을 위한 것이고, 실제 차량에서는 주행 중에 제목 한 줄만 보여 줍니다.

## 아직 남은 일 / 확인 필요

  - 고친 점: Pleos TTS·STT는 `initialize` 성공 뒤에 `setLocale`을 불러야 합니다(전에는 순서가 반대라 기본 TTS로 넘어갔음). 오디오 포커스 요청을 하나만 쓰도록 바꿔, ▶ 시작을 다시 누르면 이야기가 바로 멈추던 문제를 고쳤습니다. 경고등 읽기에 필요한 `PRIVATE_CAR_SAFETY` 권한을 넣었습니다.
  - 아직 에뮬레이터에서 못 해 본 것: 기어를 D로 바꾼 주행 중 음성 대답, Virtual Console로 넣는 경고등 신호, 경유지 추가. 이 PC(메모리 8GB)에서는 에뮬레이터가 오래 켜져 있으면 차량 서비스가 멈춰 시험을 이어 가지 못했습니다.

- 쉼터 후보는 **내비 길 안내 정보(TBT)의 전방 휴게소·졸음쉼터**(`TURN_ENTER_SERVICEAREA`, `TURN_RESTAREA`, 1~50km 앞)에서만 고릅니다. 좌표 직선거리만으로 고르면 반대 방향 휴게소를 권할 수 있기 때문입니다.

  - TBT 거리는 미터 단위로 가정했습니다(에뮬레이터 확인 필요).
- 쉼터 권유 지표(권유·수락·거절·무응답·도착 횟수, 졸음 경고 중 권유·도착)를 `RestMetrics`로 셉니다. 횟수만 세고 위치는 남기지 않으며, 앱을 닫을 때 로그(`Gilstory` 태그)에 남깁니다. 기획서의 성공 지표(쉼터 권유 수락률, 경고 뒤 휴식률)를 재는 용도입니다.

## 이야기 콘텐츠 원칙

- **지역·역사 이야기**: 한국사·세계사에서 널리 확인되는 사실만 썼고, 각 이야기의 `source` 항목에 근거를 적었습니다. 전설은 "전해져요"로 구분했습니다. 제출 전에 지자체·관광공사 자료와 한 번 더 대조하는 것을 권합니다.
- **오싹한 이야기**: 장화홍련전(조선 후기 고전소설)과 빨간 마스크(도시 괴담)는 줄거리만 가져와 새 문장으로 썼습니다. 깜짝 놀래키는 효과음과 잔인한 묘사는 넣지 않았습니다.
- **개그**: 방송·유튜브 개그 코너의 대사는 저작권이 있어 쓰지 않았습니다. 콩트 형식을 살린 창작 대본입니다.
- **생각하는 이야기**: 유튜브 영상 내레이션은 쓰지 않았습니다. 에피쿠로스, 세네카, 에픽테토스, 장자, 논어처럼 저작권이 끝난 고전을 바탕으로 새로 썼습니다.
- 실제 서비스에서 방송 개그나 유튜브 채널 콘텐츠를 쓰려면 해당 제작사와 이용 계약이 필요합니다.
